# Villager Talk (Fabric 1.21.11)

Talk in chat near a villager (within 8 blocks) and it answers. Say a villager's name to pick who answers.

Topics: money, death, family, emotions, gear, armour, the village, jokes (both ways), questions the villager asks you.
Orders: follow me, stop following, stay, you can move, come here, jump, dance, look at me.
Say "help" to a villager for the list.

Install: put the jar from the GitHub build into your mods folder with Fabric API.
